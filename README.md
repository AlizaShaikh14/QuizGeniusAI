# QuizGeniusAI

An AI-powered Quiz Management System built using React, Spring Boot, MySQL, and Gemini AI. The platform allows administrators to generate quizzes dynamically and users to attempt quizzes, view results, and track their performance.

---

## Features

### Admin Module

* AI-based Quiz Generation
* Quiz Management
* Analytics Dashboard
* Performance Charts
* Leaderboard
* Delete Quiz Functionality

### User Module

* User Registration and Login
* Attempt Quizzes
* View Results
* My Quizzes History
* Leaderboard
* Profile Management
